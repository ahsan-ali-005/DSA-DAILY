# 🧠 DSA Daily

> One LeetCode problem a day. Not for the count, for the patterns.

A 130+-day LeetCode journey in Python to build stronger problem-solving and pattern recognition.

---

## 🎯 Goal

Solve 130+ carefully selected problems, one per day.

The goal isn't to chase a number. The goal is to:

- Understand the logic behind every solution
- Recognize common DSA patterns
- Solve problems I've never seen before
- Practice consistently
- Build a public learning record

**Understand → Solve → Recognize the pattern → Review → Repeat**
